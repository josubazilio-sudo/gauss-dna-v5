Definir o fluxo oficial de desenvolvimento do QuantOS.

Nenhuma etapa poderá ser ignorada.

### REGRAS

Nunca pular etapas.

Nunca implementar diretamente em produção.

Nunca aprovar alterações sem evidências.

Nunca finalizar uma tarefa sem atualizar a documentação.

Sempre registrar lições aprendidas.
