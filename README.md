# QuantOS

Sistema Operacional para Inteligência Quantitativa.

Framework independente para trading quantitativo institucional. O QuantOS fornece inteligência, scanner, scoring, gestão de risco, auditoria e backtest para qualquer bot de qualquer exchange.

Missão: construir a melhor plataforma de inteligência para trading quantitativo — segura, modular, evolutiva e baseada em evidências.
